# Microscope GUI

Microscope GUI is a Python application for controlling a semi-parallel microscope system used in adaptive RESOLFT microscopy experiments.

Reference: R. Lin and I. Testa, "Adaptive RESOLFT microscopy," in Optica Imaging Congress 2024 (3D, AOMS, COSI, ISA, pcAOP), Technical Digest Series (Optica Publishing Group, 2024), paper OW1F.1.
